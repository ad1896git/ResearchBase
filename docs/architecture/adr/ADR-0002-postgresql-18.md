# ADR-0002: PostgreSQL 18

- Status: Accepted
- Context: Scientific persistence and integration tests require PostgreSQL semantics.
- Decision: Use PostgreSQL 18.x as the Phase 1 database baseline.
- Consequences: SQLite is not a substitute for integration or migration gates.
- Rejected alternatives: SQLite, MySQL, and PostgreSQL 19 beta.
- Upstream authority: TDG-1
- Scope: Phase 1
