# Immutability Report

The historical test captures before/after material rows for Run, Measurement, StatisticalResult, ClaimVersion,
EvidenceRelation, DatasetSnapshot, ArtifactVersion, MetricDefinitionVersion, and ExperimentSpecVersion. Fresh
reads after later scientific advancement and governance/correction actions compare the material fields and exact
reference IDs.

The immutable rows and hashes remain identical. Legal version advancement changes only the status fields permitted
by the version contract; no later Run, observation, or CorrectionRecord changes original scientific material.
